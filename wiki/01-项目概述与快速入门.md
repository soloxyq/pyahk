# 01 — 快速入门

> 5 分钟从零跑起来。详细架构看 [02-架构与通信](02-架构与核心概念.md)。

## 项目是什么

pyahk 是一个 ARPG 游戏自动化辅助工具,用 Python 做"看屏幕+决策",用 AutoHotkey v2 做"按键盘"。
目标游戏:暗黑破坏神 4 / 流放之路 2 / Torchlight Infinite。

## 系统要求

- **OS**:Windows 10/11(必须,DXGI 与 AHK 强依赖)
- **Python**:3.7+(开发用 3.10+)
- **AutoHotkey**:v2.0(默认路径 `D:\Program Files\AutoHotkey\v2\AutoHotkey64.exe`,可在 `torchlight_assistant/config/ahk_config.py` 修改)
- **Visual C++ Build Tools**:用于编译 native_capture C++ 库(可选,二进制已随仓库)

## 安装

```bash
git clone <repo-url> pyahk
cd pyahk

# Python 依赖
pip install -r requirements.txt

# (可选) 重新编译 C++ 捕获库
cd native_capture && build.bat && cd ..
```

`requirements.txt` 当前依赖(2025.10 重构后):
```
PySide6>=6.5.0    # GUI
psutil>=5.9.0     # 进程列表(目标窗口选择)
pynput>=1.7.6     # 仅 GUI "录制按键" 便利用,核心输入不依赖
Pillow>=9.0.0     # 图像
mss>=9.0.1        # 备用截屏
numpy>=1.20.0
opencv-python>=4.5.0
pywin32>=306      # Windows API
paddleocr>=3.7.0  # OCR(PaddleOCR 3.x,HP/MP 数字识别)
```

> ℹ️ **核心输入执行不再依赖 `pynput`**(2025.10.16 迁移到 AHK 子进程)。GUI 的按键录制优先用 `pynput`,同时有 Qt 本地事件兜底和手动输入；缺失 `pynput` 不影响主功能。
>
> PaddleOCR 3.x 仍需要另装 `paddlepaddle` 或 `paddlepaddle-gpu`;GPU 版按 PaddlePaddle 官方索引安装,不要直接从 PyPI 猜版本。

## 启动

```bash
python main.py
```

启动顺序:
1. PySide6 创建 QApplication
2. 安装 `AHKEventFilter` 全局原生事件过滤器(接 WM_COPYDATA)
3. 启动 `hold_server_extended.ahk` 子进程
4. 等待 1.5s,Python 通过 PING 确认 AHK 就绪
5. 注册 F8/F7/F9 永久根热键
6. 加载默认配置 `default.json`,显示主窗口

如果启动报错"无法连接到AHK服务器":检查 `ahk_config.py` 里的 `AHK_PATH` 是否指向你机器上真实的 AutoHotkey64.exe。

## 4 个全局热键

| 键 | 功能 |
|----|------|
| **F8** | STOPPED ↔ READY 切换。READY 时主窗口隐藏,显示 OSD 状态栏 |
| **Z**  | READY → RUNNING(开始执行) / RUNNING ↔ PAUSED |
| **F7** | 启停装备词缀洗练(独立模式,仅 STOPPED 可启动) |
| **F9** | 准备/停止自动寻路(独立模式;Z 才启动执行) |

> 洗练和寻路当前仅是初步实现,核心使用场景是 F8 + Z 的技能/资源自动化。

## 最小可用配置

`default.json` 已含合理默认。手动写一个最简版:

```json
{
  "skills": {
    "Skill1": {
      "Enabled": true,
      "Key": "1",
      "TriggerMode": 0,
      "Timer": 1000,
      "Priority": false
    }
  },
  "global": {
    "sequence_enabled": false,
    "macro_steps": [],
    "boss_mode_hotkey": "",
    "cooldown_checker_interval": 100,
    "capture_interval": 40,
    "window_activation": {
      "enabled": true,
      "ahk_class": "",
      "ahk_exe": "notepad++.exe"
    },
    "resource_management": {
      "hp_config": {"enabled": false},
      "mp_config": {"enabled": false}
    },
    "stationary_mode_config": {
      "hotkey": "x",
      "mode_type": "shift_modifier",
      "force_move_hotkey": "a",
      "force_move_replacement_key": "f",
      "force_move_passthrough_keys": []
    },
    "priority_keys": {
      "enabled": false
    }
  }
}
```

效果:每秒按一次 1 键。配置详细字段说明见 [04-配置 JSON Schema](04-配置与条件系统.md)。

## 第一次跑通 Checklist

1. ✅ `python main.py` 启动无报错
2. ✅ 主窗口可见,标题为"TorchLightAssistant_MainWindow_12345"
3. ✅ 在 GUI 选目标窗口(如 notepad++.exe)并保存配置
4. ✅ 切到目标窗口,按 F8(主窗口应隐藏,出现 OSD)
5. ✅ 按 Z 开始执行,看是否 1 秒按一次 1 键
6. ✅ 按 Z 暂停,按 F8 完全停止

跑不通?去 [06-调试与排查](06-调试、部署与故障排查.md) 找症状对应章节。
